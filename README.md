Detection of numerical anomalies based on images of chromosomes

Numerical anomalies are conditions where the number of chromosomes is more or less than normal. For humans, they have 46 chromosomes (23 pairs).
Numerical anomalies can lead to certain disorders like down syndrome (trisomy 21)

The model used is YOLOv8 from ultralytics for object detection and classification : https://docs.ultralytics.com/models/yolov8/
